# EWJ Reader — Android app

An installable Android build of the ReadAloud / EWJ Document Reader screens
exported from Stitch. The exports are static HTML mockups, so this wraps them in
a single-activity WebView shell, vendors every remote dependency so the app works
with no network, and wires the screens together into something you can navigate
on a phone.

The prebuilt APK is at [`dist/EWJ-Reader-debug.apk`](dist/EWJ-Reader-debug.apk)
(package `com.expeditionswithjo.ewjreader`, minSdk 24, targetSdk 34).

## Installing

Copy the APK to an Android phone and open it. Android will ask you to allow
installing from unknown sources, since this is signed with a locally generated
key rather than a Play Store one. To install over ADB:

```bash
adb install -r android/dist/EWJ-Reader-debug.apk
```

## What the app does

- Launches on the storage-permission welcome screen. Granting takes you to the
  library, and later launches skip straight there (remembered in `localStorage`).
- The bottom nav bar routes between Library, Player and Settings on every screen
  that has one; back arrows use WebView history, as does the hardware back button.
- The discreet tab on the right edge opens a sheet listing all 13 screens, so the
  variants that aren't in the main flow (empty library, EWJ-themed reader and
  settings, import-from-device, about and legal) are still reachable.
- The player's play/pause button reads the page text aloud through Android's
  text-to-speech engine, via the `EwjTts` JavaScript bridge in `MainActivity`.
  Everything else is still mockup: there is no PDF parsing, import or storage.

## Layout

```
stitch/            the raw Stitch export, one directory per screen
vendor/            Tailwind's CDN runtime, Google Fonts (Inter, Merriweather,
                   Material Symbols) and the mockups' cover images, all local
tools/build_www.py rewrites the exports into an offline bundle
tools/app.js       navigation, screen picker and TTS wiring injected into pages
tools/make_icons.py launcher icons cut from the logo export
tools/build_apk.sh  compile, dex, align and sign, without Gradle
app/src/main/      manifest, MainActivity, resources; assets/www is generated
```

`app/src/main/assets/www` is build output and is regenerated by `build_apk.sh` —
edit `tools/app.js` or the files under `stitch/`, not the bundle.

## Building

Needs a JDK and an Android SDK with `platforms/android-34` and
`build-tools/35.0.0`:

```bash
export ANDROID_HOME=/path/to/android-sdk
cd android && ./tools/build_apk.sh     # -> build/EWJ-Reader-debug.apk
```

Two things worth knowing:

- Build-tools **35.0.0 or newer** is required. The `d8` in 34.0.0 crashes with a
  `NullPointerException` on any anonymous inner class when run under JDK 21.
- The script generates a signing key at `build/debug.keystore` on first run and
  reuses it after. That file is gitignored, so a build on a fresh checkout gets a
  new key and Android will refuse to install it over an existing copy — uninstall
  first, or keep the keystore if you want upgradeable builds.

To ship this for real, replace the generated key with a keystore you control and
raise `versionCode` in `AndroidManifest.xml` for each release.
